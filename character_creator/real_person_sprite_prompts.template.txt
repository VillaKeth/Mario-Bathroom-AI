# ============================================================================
# REAL-PERSON SPRITE PROMPT TEMPLATE
# ============================================================================
# 39 pose blocks in mcp_chatgpt/batch_sprites.py format. Fill in TWO
# placeholders below, then paste blocks into any image generator.
#
#   {{NAME}}        -> character name (cosmetic; appears in the header only)
#   {{APPEARANCE}}  -> the appearance paragraph, repeated in every block
#
# Find-and-replace both, everywhere, then save each result to the path named
# at the top of its block: characters/<char>/sprites/<path>.png
# Generate on a plain/white background — the app cuts it out with rembg.
#
# ----------------------------------------------------------------------------
# WRITING {{APPEARANCE}} FOR A REAL PERSON — READ THIS
# ----------------------------------------------------------------------------
# Describe ATTRIBUTES, never the person's name. Two reasons, both practical:
#
#   1. Most backends (Pollinations/flux, Gemini, HuggingFace) restrict
#      identifiable real people — public figures especially. Naming them gets
#      you a refusal or a generic face that isn't them anyway.
#   2. With no reference image, a named face drifts badly across 39 separate
#      generations. An explicit feature checklist lands in the same place
#      every time. That is the whole reason the March 7th set came out
#      consistent.
#
# Write it in this order, one paragraph, no line breaks:
#
#   build & age -> hair -> face -> clothing -> posture -> render notes
#
# END IT WITH A PERIOD. The pose direction is appended straight after it,
# so without one you get "...plain neutral background walking in confidently".
#
# Then add NEGATIVE CONSTRAINTS. These do more work than they look like:
#   "NOT chibi, NOT a caricature, NOT cartoonish proportions, normal adult
#    head-to-body ratio, NOT a child"
#
# ----------------------------------------------------------------------------
# WORKED EXAMPLE (swap for your own)
# ----------------------------------------------------------------------------
# a tall lean man in his early sixties with a narrow build and long limbs,
# short greying black hair cropped close, high forehead, warm easy smile with
# deep laugh lines around the eyes, clean shaven, wearing a navy two-button
# suit over a light blue open-collar shirt with no tie and sleeves slightly
# rolled, relaxed confident posture with weight on one leg, normal adult
# head-to-body ratio, NOT chibi, NOT a caricature, NOT cartoonish, NOT a
# child, detailed realistic proportions, plain neutral background
#
# Another shape, different subject:
#
# a short energetic woman in her mid thirties with a stocky athletic build,
# dark curly shoulder-length hair pulled back loosely, round face with heavy
# eyebrows and a crooked grin, wearing a mustard cardigan over a white tee
# and dark jeans, hands usually mid-gesture, normal adult head-to-body ratio,
# NOT chibi, NOT a caricature, NOT cartoonish, plain neutral background
#
# ----------------------------------------------------------------------------
# ART STYLE
# ----------------------------------------------------------------------------
# The style phrase is ALREADY BAKED INTO every block below — do not add it
# separately, you would be duplicating it. These blocks use 3d_figurine:
#
#   ", 3D rendered figurine style, clean gray studio background, full body
#    shot, highly detailed, high quality, soft studio lighting"
#
# To switch styles, find-and-replace that exact phrase in every block with one
# of these (from ART_STYLE_SUFFIXES in character_creator/sprite_generator.py):
#
#   realistic  -> ", photorealistic 3D render, unreal engine style, detailed
#                   textures, studio lighting, full body"
#   cartoon    -> ", cartoon style, bold outlines, bright colors, expressive,
#                   full body shot, clean background"
#   anime      -> ", anime art style, cel-shaded, clean lines, vibrant colors,
#                   full body shot, studio background"
#   pixel_art  -> ", pixel art style, 16-bit, clean pixelated edges, retro
#                   game aesthetic, full body"
#
# For a real-person look, 3d_figurine (default here) and realistic both work.
# 3d_figurine tends to stay more consistent across a 39-image set.
#
# ----------------------------------------------------------------------------
# REGENERATING THIS FILE FROM A CHARACTER
# ----------------------------------------------------------------------------
# Once visuals.visual_description and visuals.art_style are set in
# characters/<char>/character.yaml, regenerate the real file with:
#
#   ./venv/Scripts/python.exe -c "
#   from character_creator.sprite_generator import write_sprite_prompts_file
#   print(write_sprite_prompts_file('characters/<char>'), 'blocks')"
#
# That is the authoritative path — this template just lets you work by hand.
# ============================================================================
