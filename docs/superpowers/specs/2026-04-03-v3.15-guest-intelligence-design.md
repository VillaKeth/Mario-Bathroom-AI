# v3.15 Guest Intelligence — Design Spec

## Problem Statement

Mario's face detection, voice identification, and emotion tracking are three independent systems with no unified identity. Face IDs, voice IDs, and mood data use different schemas and don't cross-reference. When 4-5 people enter the bathroom together, Mario can't greet them individually or track who's talking. Mood data is global (not per-guest) and lost between bathroom visits within the same night.

## Proposed Approach

Create a **unified GuestProfile system** that merges face recognition, voice identification, and mood tracking into a single per-guest identity. Voice is the primary identifier (people talk more than they face the camera), face supplements and enables group greetings. Mood is tracked in-memory per-guest for the duration of a party night.

## Scope

### In Scope
- Unified GuestProfile data model (new file: `server/guest_profiles.py`)
- Fix `person_detected` event routing (currently buried in health_ping handler)
- Multi-face detection → group greetings (up to 5 people)
- Per-guest mood tracking within a single party night (in-memory)
- Mood trend calculation (improving/stable/declining)
- LLM context injection with guest-specific info
- Face-voice identity merging and conflict resolution
- Jacob VIP auto-recognition (pre-registered voice + face on Threadripper)
- Comprehensive test suite with mocked Qdrant/camera

### Out of Scope
- Cross-party mood persistence (different nights)
- Facial expression → emotion recognition
- Speaker diarization (multiple simultaneous speakers)
- SD bathroom background generation (deferred to Threadripper)
- Webcam hardware setup (no camera on dev system)

## Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Primary identifier | Voice | People talk to Mario more often than they face the camera |
| Identity merge strategy | Voice wins conflicts | Voice is more reliable in bathroom lighting; face angles vary |
| Mood persistence | In-memory, single night | Simpler, clears on restart = new party. Cross-night is YAGNI |
| Multi-person handling | Greet all faces, converse with speaker | Natural behavior; avoids complex speaker diarization |
| Storage | In-memory Dict + Qdrant backends | GuestProfiles are runtime; Qdrant stores persistent face/voice vectors |
| Mood trend window | Last 3 interactions | Responsive to recent changes without being noisy |

```python
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
import uuid

@dataclass
class MoodEntry:
    timestamp: datetime
    emotion: str        # One of 26 emotions from emotions.py
    energy: float       # 0.0 to 1.0

@dataclass
class GuestProfile:
    name: str                                    # "Jake", "Mystery Guest #1"
    guest_id: str = field(default_factory=lambda: str(uuid.uuid4()))

    # Identity sources (linked to Qdrant point IDs)
    voice_id: Optional[str] = None               # Qdrant mario_voices point ID
    face_ids: list[str] = field(default_factory=list)  # Qdrant mario_faces point IDs

    # Within-night tracking
    first_seen: datetime = field(default_factory=datetime.now)
    last_seen: datetime = field(default_factory=datetime.now)
    visit_count: int = 1                         # Bathroom entries tonight
    total_interactions: int = 0                   # Messages exchanged

    # Mood (in-memory, single night)
    mood_history: list[MoodEntry] = field(default_factory=list)

    # Context
    topics_discussed: list[str] = field(default_factory=list)
    entered_with: list[str] = field(default_factory=list)

    @property
    def current_mood(self) -> str:
        return self.mood_history[-1].emotion if self.mood_history else "neutral"

    @property
    def current_energy(self) -> float:
        return self.mood_history[-1].energy if self.mood_history else 0.5

    @property
    def mood_trend(self) -> str:
        """Calculate trend from last 3 mood entries."""
        if len(self.mood_history) < 2:
            return "stable"
        recent = self.mood_history[-3:]
        energies = [m.energy for m in recent]
        delta = energies[-1] - energies[0]
        if delta > 0.15:
            return "improving"
        elif delta < -0.15:
            return "declining"
        return "stable"
```

### GuestProfileManager

```python
class GuestProfileManager:
    """In-memory guest identity system. Clears on restart (= new party night)."""

    def __init__(self):
        self._profiles: dict[str, GuestProfile] = {}  # name → profile
        self._voice_map: dict[str, str] = {}           # voice_id → name
        self._face_map: dict[str, str] = {}            # face_id → name
        self._active_guests: set[str] = set()          # currently in bathroom
        self._mystery_counter: int = 0

    def identify_by_voice(self, name: str, voice_id: str) -> GuestProfile:
        """Find or create profile from voice identification."""
        # Check if voice_id already linked to a profile
        if voice_id in self._voice_map:
            existing_name = self._voice_map[voice_id]
            profile = self._profiles[existing_name]
            profile.last_seen = datetime.now()
            profile.total_interactions += 1
            return profile

        # Check if name already exists (from face detection)
        if name in self._profiles:
            profile = self._profiles[name]
            profile.voice_id = voice_id
            self._voice_map[voice_id] = name
            profile.last_seen = datetime.now()
            profile.total_interactions += 1
            return profile

        # New guest
        profile = GuestProfile(name=name, voice_id=voice_id)
        self._profiles[name] = profile
        self._voice_map[voice_id] = name
        self._active_guests.add(name)
        return profile

    def identify_by_face(self, name: str, face_id: str) -> GuestProfile:
        """Find or create profile from face detection."""
        if face_id in self._face_map:
            existing_name = self._face_map[face_id]
            return self._profiles[existing_name]

        if name in self._profiles:
            profile = self._profiles[name]
            if face_id not in profile.face_ids:
                profile.face_ids.append(face_id)
            self._face_map[face_id] = name
            profile.last_seen = datetime.now()
            return profile

        profile = GuestProfile(name=name)
        profile.face_ids.append(face_id)
        self._profiles[name] = profile
        self._face_map[face_id] = name
        self._active_guests.add(name)
        return profile

    def create_mystery_guest(self) -> GuestProfile:
        """Create profile for unidentified guest."""
        self._mystery_counter += 1
        name = f"Mystery Guest #{self._mystery_counter}"
        profile = GuestProfile(name=name)
        self._profiles[name] = profile
        self._active_guests.add(name)
        return profile

    def rename_guest(self, old_name: str, new_name: str) -> GuestProfile:
        """Rename a mystery guest after 'Who are you?' response."""
        if old_name not in self._profiles:
            raise KeyError(f"Guest {old_name} not found")
        profile = self._profiles.pop(old_name)
        profile.name = new_name
        self._profiles[new_name] = profile
        self._active_guests.discard(old_name)
        self._active_guests.add(new_name)
        # Update reverse maps
        for vid, n in list(self._voice_map.items()):
            if n == old_name:
                self._voice_map[vid] = new_name
        for fid, n in list(self._face_map.items()):
            if n == old_name:
                self._face_map[fid] = new_name
        return profile

    def record_mood(self, name: str, emotion: str, energy: float):
        """Record mood entry for a guest."""
        if name in self._profiles:
            self._profiles[name].mood_history.append(
                MoodEntry(timestamp=datetime.now(), emotion=emotion, energy=energy)
            )

    def record_topic(self, name: str, topic: str):
        """Record a conversation topic for a guest."""
        if name in self._profiles:
            topics = self._profiles[name].topics_discussed
            if topic not in topics:
                topics.append(topic)
                # Keep last 10 topics
                if len(topics) > 10:
                    topics.pop(0)

    def guest_entered(self, name: str):
        """Mark guest as entering bathroom."""
        self._active_guests.add(name)
        if name in self._profiles:
            self._profiles[name].visit_count += 1
            self._profiles[name].last_seen = datetime.now()

    def guest_exited(self, name: str):
        """Mark guest as leaving bathroom."""
        self._active_guests.discard(name)

    def get_active_guests(self) -> list[str]:
        """Get names of guests currently in bathroom."""
        return list(self._active_guests)

    def get_guest_context(self, name: str) -> str:
        """Build LLM context string for a specific guest."""
        if name not in self._profiles:
            return f"Guest: Unknown person"

        p = self._profiles[name]
        parts = [f"Guest: {p.name}"]

        # Identity confidence
        sources = []
        if p.voice_id:
            sources.append("voice-confirmed")
        if p.face_ids:
            sources.append("face-recognized")
        if sources:
            parts.append(f"ID: {', '.join(sources)}")

        # Visit info
        if p.visit_count > 1:
            parts.append(f"Visit #{p.visit_count} tonight")

        # Mood
        if p.mood_history:
            parts.append(f"Mood: {p.current_mood} (energy {p.current_energy:.1f}, {p.mood_trend})")

        # Topics
        if p.topics_discussed:
            parts.append(f"Topics tonight: {', '.join(p.topics_discussed[-5:])}")

        # Group
        active = self.get_active_guests()
        others = [g for g in active if g != name]
        if others:
            parts.append(f"Currently with: {', '.join(others)}")

        return "\n".join(parts)

    def get_all_profiles(self) -> dict[str, GuestProfile]:
        """Get all profiles (for dashboard/debugging)."""
        return dict(self._profiles)
```

### 6. Greeting Debounce

Prevent Mario from greeting the same person every frame:

```python
_last_greeted: dict[str, datetime] = {}
GREETING_COOLDOWN = 60  # seconds

def should_greet(profile: GuestProfile) -> bool:
    last = _last_greeted.get(profile.name)
    if last and (datetime.now() - last).total_seconds() < GREETING_COOLDOWN:
        return False
    _last_greeted[profile.name] = datetime.now()
    return True
```

## Error Handling

- **Qdrant down:** Fall back to SQLite for face/voice lookup. GuestProfiles still work (voice-only mode).
- **Camera disconnected:** Voice-only identification. Log warning, don't crash.
- **face_recognition import fails:** Skip face detection entirely, voice-only mode.
- **Multiple people claim same name:** Keep first profile, log conflict.
- **Server restart mid-party:** All GuestProfiles lost (by design). Guests re-identified on next interaction.
